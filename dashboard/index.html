How the value is worked out

Implied value is the entry's own claim, never make.fun's, and it is not a prediction that a token will be issued or when. It is worked out from the snapshot's own figures alone:

implied value = TVL × category multiple × growth × maturity × breadth

  • Category multiple. For each category, the median market cap per dollar of TVL among the protocols whose token already trades — the market's own pricing, read out of this snapshot. Each live protocol's ratio is capped at 5× before the median, and a category with fewer than ten live protocols is pulled toward the market median, so one outlier never prices a whole category. A category with no live protocol takes the market median.
  • Growth. The protocol's seven-day TVL change, clamped to −60%…+120%, moves the value by 0.6× the change: a protocol growing 10% in a week is worth 6% more than its TVL alone says.
  • Maturity. How long the protocol has run with no token: 0.60 for a brand-new listing, rising to 1.00 after three years. A protocol that held users for years without issuing a token has more pent-up launch value than one listed last month.
  • Breadth. 1.00 on one chain, +0.03 per extra chain, up to 1.12: a protocol live on several chains reaches more farmers than a single-chain one.

No protocol name is ever special-cased: the same function scores every row. Exchanges and versioned pools are not ranked, and neither are wrapped, staked or bridged products of a token that already trades — a wrapped token is not a launch waiting to happen.
